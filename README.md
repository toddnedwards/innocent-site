# innocent-site

A professional band website built with HTML, CSS, and JavaScript.

## Structure

```
innocent-site/
├── index.html          # Home page
├── about.html          # About the band
├── music.html          # Music/discography
├── videos.html         # Music videos and performances
├── bookings.html       # Live bookings and tour dates
├── contact.html        # Contact form
├── more.html           # Additional content
├── css/
│   └── styles.css      # Main stylesheet
├── js/
│   └── script.js       # JavaScript functionality
└── media/              # Media assets
    ├── images/         # Image files
    ├── audio/          # Audio files
    └── video/          # Video files
```

## Features

- Responsive design for mobile and desktop
- Interactive navigation with active page highlighting
- Contact form with client-side validation
- Clean, modern UI with professional styling
- Organized media folder structure

## Usage

Simply open `index.html` in a web browser or serve the files with any web server.

For development, you can use a simple HTTP server:
```bash
python3 -m http.server 8000
```

Then navigate to `http://localhost:8000` in your browser.
